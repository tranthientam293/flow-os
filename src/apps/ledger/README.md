# Ledger

Daily expense tracker: write down what you spend each day and see where your money goes.

## Routes

Nested under the platform's `/apps/ledger/*` (see `LedgerApp.tsx`, `constants/routes.ts`). Both main pages read the month from `?month=YYYY-MM` (missing, invalid or future means the current month), so the header tabs and "See all" keep it and it survives a reload:

| Path                    | Screen                                                                    |
| ----------------------- | ------------------------------------------------------------------------- |
| `/apps/ledger`          | **Dashboard**: the month at a glance                                      |
| `/apps/ledger/expenses` | **Expenses**: the month's expenses, grouped by day                        |
| `/apps/ledger/settings` | **Settings**: monthly limit, your account (sign-in email), Back to flowOS |

Any other path goes back to the Dashboard.

## Tables

Migrations: `supabase/migrations/20261014000000_app_ledger_init.sql`, `20261014010000_app_ledger_settings.sql`.

| Table             | Purpose                                                                                                                                                                                                     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ledger_expenses` | One row per expense: `amount` (whole đồng, > 0), `category_id` (an id from `constants/categories.ts`), `note` (up to 200 characters), `spent_on` (day). RLS: each user reads and writes only their own rows |
| `ledger_settings` | One row per user (`user_id` is the key), created on first save: `monthly_limit` (whole đồng, > 0; null means no limit). RLS: each user reads, adds and updates only their own row.                          |
